# Quickstart

## Prerequisites

- Python 3.11+
- A virtual environment

## Setup

```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

## Run the app

```bash
streamlit run app.py
```

## Validation

1. Paste a sample prior authorization request into the sidebar.
2. Click Run AI Pipeline.
3. Confirm the UI shows classification, evidence matches, gap analysis, summary content, and a status update.
